# Public garden artwork

Approved, web-ready artwork used by the public garden belongs here.

Suggested folders:

- `essays/`
- `poems/`
- `tech/`
- `sound/`
- `ornaments/`

Use stable descriptive filenames and keep images to the approved red-clay, warm-paper, charcoal, and cobalt illustration system. Store prompts and provenance notes outside `public/`; this directory is public output. Before publishing an asset, record its intended use and alt-text decision in the project's artwork manifest. Decorative flourishes should use empty alt text; meaningful images need concise descriptive alt text.
